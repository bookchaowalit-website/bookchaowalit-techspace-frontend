# Techspace design direction

## Product world
Techspace is an evidence-backed catalogue of tools actually used. Each entry is a reference note with context, not a badge wall or a ranking.

## Visual direction
- Seed: a1ed5691 — assigned centre-rail reference-setting direction.
- Material: warm ruled paper, a stable centre rail, red editorial marks, blue source links.
- Typography: large serif index headings with mono register labels and field notes.
- Composition: the filter register is the annotation margin; the main list is the reference rail.

## Interaction
- Search, category, status, experience, and minimum-rating filters remain functional.
- Each entry continues to link to /stack/[slug].
- On mobile the filter register becomes an explicit drawer-like section and entries collapse into a readable three-column rhythm.

## Constraints
- Keep data sourced from the current MDX/data pipeline.
- Never turn ratings into authority claims; they are personal notes only.
- Preserve MCP/API discovery routes and detail pages.
- Avoid the previous generic card wall and stale “website collection” wording.
